# Website Tanya Jawab AI

Project Next.js sederhana untuk tampilan awal website tanya-jawab AI.

## Teknologi

- Next.js App Router
- TypeScript
- Tailwind CSS

## Menjalankan Project

```bash
npm run dev
```

Buka `http://127.0.0.1:3000` di browser.

## Catatan

Project ini belum memakai OpenAI API, database, login, atau upload file.
